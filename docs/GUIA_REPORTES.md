# Guia de Reportes

## Reportes administrativos/financieros

Los reportes finales son de caja y facturacion:

- Ventas del dia.
- Ventas por rango de fechas.
- Reporte por caja.
- Reporte por cajero.
- Reporte por categoria o servicio facturable.
- Pagos por metodo.
- Anulaciones y reversos.
- Exportaciones autorizadas si estan habilitadas.

## Uso recomendado

1. Entrar a Reportes con permiso correspondiente.
2. Seleccionar fecha o rango.
3. Aplicar filtros de caja, cajero, categoria, servicio, estado o metodo segun disponibilidad.
4. Comparar totales contra cierre de caja.
5. Exportar solo cuando el rol lo permita.

## Fuera de alcance

No existen reportes clinicos, reportes de diagnostico, citas, laboratorio clinico, farmacia clinica, triage, admisiones ni hospitalizacion.
