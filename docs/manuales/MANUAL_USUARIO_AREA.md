# Manual Del Usuario De Area

Este manual es para personal de un area hospitalaria, como laboratorio o rayos
X, que necesita consultar servicios ya pagados. Este rol no abre caja, no crea
facturas, no registra pagos y no ve reportes administrativos.

## Abrir El Sistema

1. Abra la direccion LAN entregada por administracion.
2. Inicie sesion con su usuario personal.
3. Si el sistema muestra **Servicios pagados**, ya esta en la pantalla correcta.
4. Si ve "Area no asignada", avise al administrador. No use otra cuenta.

## Consultar Servicios Pagados

1. Revise que el titulo muestre el area correcta.
2. Use **Desde** y **Hasta** para elegir el rango del dia o turno.
3. Presione **Actualizar** si cambio las fechas.
4. Revise paciente, servicio, fecha, cajero, metodo de pago y total.
5. Atienda solo servicios que aparecen como pagados para su area.

## Que Hacer Si No Aparece Un Servicio

1. Confirme con caja que el paciente ya pago.
2. Pida a caja buscar la factura en **Historial**.
3. No pida repetir la factura ni repetir el cobro a ciegas.
4. Si caja confirma pago y el servicio no aparece, avise al supervisor o
   administrador con el nombre del paciente, fecha aproximada y area.

## Que No Debe Hacer Este Rol

- No cobrar ni recibir dinero.
- No crear facturas nuevas.
- No anular facturas ni pagos.
- No cambiar precios o catalogo.
- No use esta pantalla como expediente clinico.
- No compartir capturas con datos de pacientes fuera del personal autorizado.

## Checklist Diario

- [ ] Inicie sesion con usuario propio.
- [ ] Confirme que la pantalla muestra su area asignada.
- [ ] Consulte el rango correcto del dia o turno.
- [ ] Verifique que cada servicio atendido aparezca como pagado.
- [ ] Avise a caja si un paciente dice haber pagado y no aparece en la lista.
- [ ] Cierre sesion al terminar el turno o al dejar la computadora.

## Advertencias Antes De Acciones Delicadas

- Antes de atender un servicio, confirme que aparece en **Servicios pagados**.
- Antes de pedir ayuda, revise que el rango de fechas sea correcto.
- Antes de solicitar otra factura, revise con caja en **Historial**; no pida
  repetir facturas ni cobros sin verificacion.
- No repetir facturas ni cobros para corregir una duda de area; primero caja
  debe revisar **Historial** y confirmar el pago.
- Antes de compartir informacion, confirme que la persona esta autorizada por
  el hospital.
- Si el sistema no carga o muestra permiso denegado, avise a soporte local o
  administracion. No use cuentas de otra persona.
