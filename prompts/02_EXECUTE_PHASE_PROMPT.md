# PROMPT 02 - EJECUTAR UNA FASE DEL PLAN

Implementa únicamente la fase indicada del plan aprobado.

## Antes de codificar
- Lee AGENTS.md.
- Lee la fase exacta del plan aprobado.
- Lee las referencias relacionadas con esa fase.
- Confirma los archivos que tocarás.

## Reglas
- No implementar funcionalidad fuera de la fase.
- No modificar módulos no relacionados.
- Escribir o actualizar pruebas antes o junto con la implementación.
- Usar migraciones, seeders, factories y tests cuando aplique.
- Mantener controllers delgados y lógica en services/actions.
- No usar floats para dinero.
- No romper funcionamiento offline.

## Salida esperada
1. Resumen de lo implementado.
2. Archivos modificados.
3. Pruebas agregadas.
4. Comandos ejecutados y resultado.
5. Riesgos o deuda técnica detectada.
6. Mensaje de commit sugerido.
