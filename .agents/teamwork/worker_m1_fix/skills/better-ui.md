Key concepts:
- Concentric border radius: Outer radius = inner radius + padding.
- Optical alignment over geometric alignment.
- Shadows for elevation, borders for structure.
- Interruptible animations with CSS transitions.
- Match icon stroke to text weight.
- Motion restraint (instant feedback or <=150ms on opacity/color).
- One SVG, recolored per state using currentColor.
