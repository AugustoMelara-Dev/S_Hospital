# better-ui (Local Dump)
Source: c:\Projects\S_Hospital_AI\.agents\skills\better-ui\SKILL.md
Description: Polishes and improves the UI in your project. Covers concentric border radius, optical alignment, surface depth, contextual icons, hit areas and more.

Key Rules:
1. Concentric border radius: Outer radius = inner radius + padding.
2. Optical over geometric alignment: buttons with icons need manual nudge.
3. Shadows for elevation, borders for structure. Keep borders communicating structure/state.
4. Scale on press: transform scale(0.96) or scale(0.97) on :active.
5. Tabular numbers: tabular-nums for numeric/monetary columns and counters.
6. Specify exact transitions (no transition: all).
7. Match icon stroke to text weight (1.5px / 2px).
