# UX/UI Gap Report

## Hallazgo principal

El frontend actual no comunica calidad de producto. El usuario percibe desorden porque los módulos aparecen en una sola página o con navegación insuficiente. El catálogo de servicios resulta interminable y la facturación no se siente como POS/caja.

## Brechas

1. Falta sidebar profesional.
2. Falta separación real por módulos/rutas.
3. Facturación no está optimizada para caja.
4. Catálogo no está presentado por categorías de forma dominante.
5. No hay scanner workflow.
6. Reportes básicos no son suficientes para administración.
7. Falta sistema visual consistente.
8. Tipografía/espaciado deben normalizarse.

## Impacto

- Riesgo de rechazo del cliente aunque backend funcione.
- Demostración menos convincente.
- Cajera puede sentirse perdida.
- Administración puede percibirlo como incompleto.
