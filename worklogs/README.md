# Worklogs

Usar esta carpeta para registrar avances breves de Fase 12 por fecha y fase.

## Formato sugerido

```text
YYYY-MM-DD-fase-12x.md
```

Cada worklog debe incluir:

- Rama.
- Fase.
- Alcance ejecutado.
- Pruebas corridas.
- Riesgos abiertos.
- Siguiente paso.

No usar worklogs como sustituto de commits, PRs o documentos de decision.
