## Decisiones

- La autorización de ejecución mantiene el alcance completo de la auditoría. No se presentan scripts como instalación certificada ni lectura de un archivo de copia como restauración acreditada.
- No se cambian tarifas, impuestos o catálogo existente de manera masiva. Se eliminan restricciones heredadas y se exige edición autorizada, conservando históricos.
- El acceso de recuperación debe depender de autorización del sistema operativo, nunca solo de localhost. Credenciales fuera de argumentos y logs.
- El destino es una computadora Windows; el modelo/versión de Windows y la impresora siguen pendientes para certificación física.
- Se conserva este registro porque no se permiten commits. Ningún registro antiguo se considera prueba de código modificado.
