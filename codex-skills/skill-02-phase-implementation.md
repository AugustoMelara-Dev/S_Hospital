# Skill Codex: Implementación por fase

## Disparador
Usar después de que el plan esté aprobado o aprobado con cambios menores.

## Procedimiento
1. Seleccionar una sola fase.
2. Crear o actualizar tests.
3. Implementar mínimo necesario.
4. Ejecutar quality gate.
5. Preparar resumen y commit.

## Restricciones
- No ampliar alcance.
- No mezclar fases.
- No saltar tests en reglas críticas.
